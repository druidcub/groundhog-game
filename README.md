# Groundhog Game · 土撥鼠挖寶

一款用同一支手機或平板、面對面玩的 2D 挖寶網頁遊戲。支援單人探險、雙人競賽，以及兩人合作對抗 NPC。使用純 HTML、CSS、JavaScript 與 Canvas，不需安裝遊戲或註冊帳號。

**[線上遊玩](https://druidcub.github.io/groundhog-game/)**

## 玩法

在 10 × 10 的地下世界移動，自動挖開土堆。每局重新隨機配置金幣、8 個炸藥及 12 塊石頭；所有角色的起點都是安全格。

- **金幣**：挖到就收集。總數為 `4 ×（真人玩家 + NPC 數量）+ 1`。
- **炸藥**：暈眩 3 秒，期間不能移動，不扣分。炸藥只觸發一次。
- **石頭**：第 1 下顯露、第 2 下裂開、第 3 下更多裂痕、第 4 下挖開。前三下擋住角色；所有角色共享挖掘進度。
- **其他角色**：不能穿過或重疊，但可以沿大家挖出的通道移動。

| 模式 | 參賽者 | 勝利條件 |
| --- | --- | --- |
| 單人 | 1 名真人，可選 0～3 隻 NPC | 每個角色獨立計分，先拿到 5 枚獲勝 |
| 雙人正常 | 2 名真人，可選 0～2 隻 NPC | 每個角色獨立計分，先拿到 5 枚獲勝 |
| 雙人合作 | 2 名真人，固定左右各 1 隻 NPC | 玩家隊與 NPC 隊各自加總，先拿到 9 枚的一隊獲勝 |

合作模式兩端都顯示玩家隊的加總分數。NPC 自動探索未挖開的土堆，不讀取隱藏金幣或炸藥的位置，也會挖石頭及被炸藥暈眩。

## 操作

| 玩家 | 電腦鍵盤 | 手機／平板 |
| --- | --- | --- |
| 主玩家（棕色，下方出發） | **WASD** | 下方圓形搖桿 |
| 對面玩家（紫色，上方出發） | **方向鍵** | 上方圓形搖桿 |

單人模式也可用方向鍵控制主玩家。按住搖桿外側會持續移動，拖曳可以轉向，中心死區與放手會停止。**按向螢幕哪個方向，角色就往同方向移動**，上方介面旋轉也不會反向。兩個搖桿可同時操作。

地圖也支援滑動；雙人時由手指開始的上／下半部判定玩家。手機及平板上的上方 UI 旋轉 180°，方便面對面操作；電腦的兩端 UI 都保持正向，正常與合作模式一致。觸控 Windows 筆電使用電腦配置，iPad 使用桌面版網站也會辨識為平板。

右上設定選玩家人數、模式及 NPC，按「重新開始」套用。設定視窗與背景頁面會暫停整場遊戲。

## 獲勝演出

結束時先顯示全景，再拉近獲勝角色；合作模式同時框住獲勝隊的兩隻角色。獲勝者換上開心表情並跳躍，落敗者垂頭晃動。結果面板位於操作區，演出持續到重玩。

手機／平板合作模式的玩家 2 獲勝表情旋轉 180°；NPC 隊獲勝時，藍色正向、紅色反向，讓兩位玩家各看到一隻正面的角色。電腦上的獲勝角色都保持正向。支援系統的「減少動態」偏好。

## 本機執行

直接開啟 `index.html` 即可離線玩，沒有外部套件依賴。

若需要本機伺服器，先安裝 Node.js，再執行：

```sh
git clone https://github.com/druidcub/groundhog-game.git
cd groundhog-game
node server.cjs
```

開啟 `http://localhost:4173`。手機和電腦在同一區域網路時，可用電腦的區網 IP 與 4173 埠連線；須允許防火牆存取。此伺服器僅供本機開發使用。

## 開發與驗證

```sh
node tests.cjs
```

測試包含隨機配置、金幣數量、石頭四次挖掘、暈眩、角色阻擋、NPC 探索、雙人及合作計分、裝置識別、快捷鍵與獲勝鏡頭取景。

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`style.css` | 介面與響應式版面 |
| `game-core.js` | 地圖、挖掘、計分、NPC 與勝利規則 |
| `game.js` | Canvas 繪製、搖桿、多點觸控與動畫 |
| `view-mode.js` | 裝置識別、介面朝向、快捷鍵及角色朝向 |
| `ending.js` | 獲勝取景、跳躍與失落動態 |
| `assets/` | 遊戲使用的圖像 |
| `art/` | 原始圖集、生成提示及素材來源紀錄 |
| `tests.cjs` | 不需外部套件的規則測試 |
| `server.cjs` | 本機靜態預覽伺服器 |

## 素材與授權

圖像使用 OpenAI ImageGen 生成，原圖、提示及來源紀錄保存在 `art/`。角色動態由 Canvas 對靜態圖像進行位移、旋轉與伸縮，未使用生成影片。

## PWA 安裝與離線遊玩

首次連線開啟線上遊戲後，會快取遊戲程式、所有角色圖像與圖示。設定中顯示「離線遊玩已就緒」後，可以離線重新開啟遊戲。離線功能不保存目前對局，重新開啟會開始新遊戲。

- Chrome／Edge 等支援的瀏覽器：使用瀏覽器的安裝選項；可用時，設定也會顯示「安裝到裝置」。
- iPhone／iPad：使用 Safari 分享選單的「加入主畫面」。
- 新版離線檔案準備好後，設定會顯示「更新並重新開啟」；按下會重新載入並開始新局，不會在對局中自動重開。
- PWA 安裝與 service worker 需要 HTTPS 或 localhost，直接開啟本機 HTML 仍能玩，但不會安裝 service worker。

`manifest.webmanifest` 使用相對的起始路徑及範圍，適用於 GitHub Pages 的 `/groundhog-game/`；`sw.js` 只管理本遊戲範圍的快取。修改任何快取的程式或素材時，須遞增 `sw.js` 中的 `VERSION`。

App 圖示由既有 ImageGen 土撥鼠素材縮放與加上深色背景製作；含 192／512 px 一般圖示、512 px maskable 圖示、Apple touch icon 及 favicon。


### 對向角色與設定保存

手機／平板對向操作時，玩家 2 的所有遊玩、暈眩與勝負表情均旋轉 180°；移動時使用對應方向圖，保持角色朝向與螢幕移動方向一致。玩家 2 拾取金幣的圖像、「+1」及飄動方向一起反轉。電腦保持正向。

雙人正常模式最多 2 隻 NPC，單人仍可選 0～3 隻；合作固定 2 隻。玩家人數、模式、NPC 數量儲存在目前瀏覽器的 localStorage，修改設定時即保存，重新整理／重新開啟會套用，但不保存正在玩的對局。清除網站資料會重設設定；儲存功能被瀏覽器限制時，遊戲仍能正常使用。舊有双人 3 NPC 的設定會自動修正為 2 NPC。
